Job Market Intelligence Dashboard

📊 Project Overview

A data analytics project that analyzes job market data to identify trends in job roles, skills, locations, experience levels, and salaries. The project uses Python for data cleaning and analysis and Power BI to create an interactive dashboard.

🛠️ Technologies Used

* Python
* Pandas
* Power BI
* Excel
* Data Analysis
* Data Visualization

📁 Project Contents

* Data_jobs.csv – Raw job market dataset
* Data_jobs_cleaned.xlsx – Cleaned dataset
* Python – Data cleaning and analysis scripts
* Screenshots – Dashboard screenshots
* Job_Market_analytics.pbix – Power BI dashboard

🎯 Key Objectives

* Analyze job market trends
* Identify in-demand skills
* Explore job roles and locations
* Understand experience-level requirements
* Present insights through an interactive Power BI dashboard
